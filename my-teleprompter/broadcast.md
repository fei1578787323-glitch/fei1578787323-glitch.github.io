# 播报套件

给电视台、融媒体中心、政务新闻发布、校园电视台用的方案。替代几万元的硬件提词系统，用一台 Mac 和现有的显示器。

## 功能

- **多机同步与主备热切换**：一台主机带多台从机，主持人屏、导播屏、监视器同一位置；主机出问题从机约 1 秒内从同一位置接着播。
- **Tally**：支持 NDI 和 TSL UMD 3.1 / 5.0，哪台机位在播出、在预监，提词窗上亮红框、绿框。
- **NDI 输出**：稿子作为一路 NDI 源直接进切换台或 vMix，不用采集卡。
- **节目单**：多条稿按顺序排，每条有预计时长，实际用时和计划的差实时显示；超时预警。
- **播出中改稿**：编辑在自己的电脑上改，主持人面前实时更新，正在读的那一行不动。
- **外接屏幕**：同时输出到多块屏，各自选正常或镜像，接提词器分光镜直接用。
- **外部控制器**：脚踏板、翻页笔、手柄、TSL。
- **退出清稿**：涉密场合，退出程序稿件自动清空。
- **多人稿**：「张三：」「李四：」自动着色，双主持一目了然。

## 和硬件提词系统的对比

| | 硬件提词系统 | FRMZONE 播报套件 |
|---|---|---|
| 一套的价格 | 数万元 | 一台 Mac + 软件授权 |
| 多机位 | 每机位一套硬件 | 一台主机 + 从机（旧电脑、iPad 都能当从机） |
| 主备 | 需要额外备机方案 | 内置，约 1 秒接管 |
| Tally / NDI | 高配才有 | 标配 |
| 联网激活 | — | 离线授权码，内网可用 |
| 智能跟读 | 无 | 有，脱稿插话后自动跟回 |

## 部署

- 主机：Mac（2018 年以后）。从机：Mac、iPad、iPhone 均可。
- 同一局域网即可，不需要外网；授权码离线验证。
- 现有分光镜提词器直接接外接屏输出，选镜像即可。
