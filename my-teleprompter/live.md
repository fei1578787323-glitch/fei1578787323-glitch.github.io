# 直播间套件

给电商直播间、带货基地、MCN 用的提词方案。一个房间一台 Mac 或一部手机，主播只管看着念，场控在旁边或隔壁改词。

## 直播间最常见的四个问题，各对应一个功能

| 直播间的问题 | 我们怎么解 |
|---|---|
| 话术要循环念一整场，主播念到后面越来越乱 | **循环播放**：滚到结尾自动从头，节奏不散；**声控滚动**：主播一开口就走、停下就停，回答弹幕时画面不会跑掉 |
| 运营临时改价、加赠品，得跑到主播面前改 | **导播远程改稿**：场控用自己的手机或电脑浏览器改，改动实时送到主播面前，正在念的那一行不会动 |
| 弹幕问题主播看不过来 | **弹幕并入提词窗**：弹幕和话术在同一块屏上，主播不用低头看第二块屏（目前直连 Twitch，其他平台走 OBS 浏览器源） |
| 多个直播间、多个主播轮班 | **多机同步与主备**：一台主机带多台从机；主机出问题从机一秒内接着播。**台本库**按品类整理话术，换人不换稿 |

## 一场直播的流程

1. 场控在电脑上把话术贴进来，AI 一键「改成口语」「标出重点词」，重点词在提词窗里放大变色。
2. 主播开播，提词模式选**声控滚动**或**循环播放**，屏幕放在镜头正下方。
3. 中途改价：场控在手机浏览器上改，主播面前的稿子原地更新。
4. 弹幕来了问题：场控把问题打进稿子当前位置下一行，主播念完接着往下。
5. 下播后回放页点**口播复盘**：这场语速多少、口头禅几次、卡壳在哪，下一场改。

## 硬件要求

- 一台 Mac（2018 年以后）或一部 iPhone / iPad；不需要提词器硬件，有的话也能接（镜像输出）。
- 弹幕接入目前支持 Twitch；国内平台的弹幕通过 OBS 浏览器源或手工插播。
- 全部在本机运行，话术不上传到任何服务器。

## 购买

按直播间数量授权，每个直播间一台主机 + 不限从机。装上后 **14 天全功能试用**，先用一场再决定。
